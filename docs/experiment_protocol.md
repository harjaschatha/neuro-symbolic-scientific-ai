# Evaluation protocol and evidence boundaries

## Source selection

The reported values are recalculated from existing files in `Final_Project`,
not generated by this repository's illustrative five-arm simulation.
The later Stage E archive is
`neuro_symbolic_bioprocess/ns_pipeline_outputs/stage_e_archives/job36212117_seed42/`.
Its standard and expanded result files each contain 500 unique, matched run IDs
with identical ground-truth labels and no error rows.

The archive and source reporting freeze identify seed 42, job 36212117, and
Qwen/Qwen2.5-14B-Instruct. The archived configurations and checkout commit were
copied after execution and are not verified as run-time snapshots. Local artifact
hash verification does not resolve this limitation.

## Metrics

- **Saved projection-aware accuracy:** count of stored `correct_selection=true`
  divided by 500. It preserves the historical evaluator's arm-specific targets;
  it does not independently validate the scientific correctness of those targets.
- **Exact biological accuracy:** selected label equals ground truth, interpreting
  null or empty `true_mechanism` as `baseline` according to the source audit.
  Unavailable mechanisms count as errors.
- **Fixed-family accuracy:** map product inhibition, oxygen limitation, and
  maintenance-inhibition to inhibition; map switching-inhibition to switching;
  retain other labels. Apply this identical mapping to truth and selection.
- **Paired changes:** compare correctness on the same run IDs. A rescue is an
  incorrect standard decision becoming correct in the expanded arm; harm is the
  reverse. These counts are descriptive for this development cohort.

No hallucination rate, parameter MAPE, RSS, latency, training history, or hardware
performance is inferred from these accuracy counts. The earlier five-arm toy
table was removed because its simulated outputs did not substantiate research
performance claims.

## Earlier report provenance

`report_500/results.json` contains 449 saved correct decisions (89.8%) and 375
exact matches (75.0%). Seventy-four switching-to-maintenance selections account
for the difference. The similarly named local ablation full arm has 376 saved
correct decisions (75.2%) and a different hash. The source project's
`REPORT_RESULTS_FREEZE.md` requires reconciliation with the original HPC artifact.
This repository retains both as separate, labeled evidence sets and does not
claim to have completed that remote provenance check.

## Reproduction

From this repository:

```bash
python scripts/export_verified_results.py --check
python scripts/export_verified_results.py --check --source-root /Users/harjaschatha/Final_Project
```

To regenerate the derived evidence from the pinned source files:

```bash
python scripts/export_verified_results.py --source-root /Users/harjaschatha/Final_Project
```

The exporter checks source hashes, row validity, unique run IDs, and matched Stage
E cohorts before producing minimal per-case records and summaries. A changed
source hash stops export and requires review. The evidence contains saved labels
and correctness flags, not full trajectories, fitted states, prompts, or model
weights; it can reproduce the reported counts but not rerun inference.
